# SimuResto — 大学食堂多智能体模拟

## 项目描述

**SimuResto** 是一个使用 Go 开发的二维多智能体模拟项目，旨在还原法国 CROUS 大学食堂的用餐流程。学生可能先在食堂外排队，进入食堂后沿共同的服务路线依次领取托盘、选择前菜、由工作人员分发主菜、付款，随后寻找座位就餐，餐后归还托盘。

模拟环境中有两类智能体：**学生**与**食堂工作人员**。学生根据自身情况移动，并自主决定继续排队还是离开等行为；工作人员主要负责分发餐食、补充菜品和收款。智能体根据自身状态和环境信息采取行动，部分行为可以具有随机性。

**智能体之间的交互：** 学生之间可以通过结伴、排队或插队等行为相互影响；学生与工作人员通过点餐、取餐和付款等信息交换完成服务流程。

## 研究问题

学生流量、工作人员数量、服务速度以及学生的个体决策，如何影响大学食堂的等待时间、拥堵程度和服务吞吐量？

## 预计开发阶段

1. **最小原型：** 模拟一名学生等待工作人员分发主菜，并继续完成付款流程，通过二维界面展示。
2. **目标模拟：** 基于原型增加学生人数、室外队伍、各服务环节、菜品补充、寻找座位与餐后离开等行为。
3. **拓展：** 加入额外影响因素，如不同时段的学生到达人数变化、工作人员数量调整，以及结伴到达、插队等社交行为。

## 关键指标

- **等待时间：** 平均等待时长及各服务环节的等待时间。
- **拥堵程度：** 队伍长度与各服务区域的人数。
- **服务吞吐量：** 单位时间内完成服务的学生人数。
- **放弃排队比例：** 在领取托盘前离开队伍的学生占比。
- **工作人员利用率：** 工作人员用于服务任务的时间占比。

通过比较不同运行条件下的这些指标，分析食堂整体运行状况的变化。
